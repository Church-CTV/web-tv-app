# Third-party notices and generated example art

`DEPENDENCY-LICENSE-INVENTORY.json` records declared npm license metadata, including
development tools. The production npm dependency graph contains only this
project's workspaces, so `THIRD-PARTY-LICENSES.json` has no external production
npm package entries. That does not clear build tools, platform SDKs, external
services or rights in the first-party source.

Vendor SDK files, customer logos, fonts and QR artwork are not supplied. The
geometric example launcher/splash images are generated from
`scripts/gen-icons.mjs`; see `assets/ASSET-PROVENANCE.md`. The legacy `roku`
filenames are not a claim to Roku artwork or trademarks. The source generator's
ownership remains part of first-party rights review.

Store signing, vendor SDK installation, platform distribution agreements and
app-specific media/branding licenses are independent operator responsibilities.
The diagnostic packages are not certified for store submission.
