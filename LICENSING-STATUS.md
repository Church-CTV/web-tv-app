# Licensing status

This is private release preparation, not an operative public source license.
`LICENSE.draft.md` and `CONTRIBUTOR-AGREEMENT.draft.md` require legal review and a
named legal licensor before use. Until then, no public grant is represented.

The intended model is royalty-free self-hosting for eligible churches, narrowly
permitted church contractors, required sharing of deployed covered modifications,
and no independent commercial operation or resale under the public grant.
Commercial managed services have separate agreements. The draft is
source-available, not OSI open source.

Some original source package manifests declare ISC. Those declarations and any
prior grants must be investigated, not silently erased or presumed revocable.
Existing third-party code retains its own licenses. This project's custom terms
can cover only rights the actual licensor owns or is authorized to grant.

Before publication, establish code ownership and contributor authority, preserve
required notices and license texts, inventory dependencies, verify every asset's
rights, and finalize eligibility, source sharing, contributor acceptance and
service/support terms. A new Git history does not create copyright ownership.

No source scanner, automated test or agent is able to certify a perfect license
or complete legal clearance. These are explicit public-release blockers.
