# Contributing

External code contributions are not yet accepted for release. The church-use
license and contributor agreement are drafts, not operative grants.

The finalized process will require recorded acceptance of contributor terms
including explicit commercial-relicensing rights. Contributors retain ownership.
Do not submit code/assets you cannot license, customer content, private
configuration, credentials or personal information.

Use synthetic fixtures and local/mocked services. Runtime changes require a
failing regression test before the fix and a passing rerun. Include actual build
and test results, dependency changes and limitations. Read `SECURITY.md` before
reporting a security issue. Contributions never authorize production deployment.
