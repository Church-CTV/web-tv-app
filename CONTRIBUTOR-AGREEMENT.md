Version 1.0 — effective 2026-11-12 — applies to contributions to any Church-CTV
repository.

Acceptance method: by opening a pull request you accept this agreement and
certify section 4. Put this line in the pull request description:

`I agree to the Church CTV Contributor Agreement v1.0 and certify the
representations in section 4.`

A maintainer records that acceptance in the merge. A pull request without it is
reviewed but not merged. Opening an issue needs no agreement.
